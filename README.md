# destiny

反思型的易經、五行工具原型。重點不是算命，而是給人一個換角度思考的方向。

## 檔案

- `wuxing-wengua.html`：五行問卦。擲硬幣起卦，得出本卦和之卦，再用上下卦的五行生剋給出解讀和反思問題。
- `wuxing-hepan.html`：五行問卦合盤。用生辰排出八字四柱，看日主和五行強弱；再起卦看這件事，最後合看陰陽和五行喜忌。

兩個都是單一 HTML 檔，直接用瀏覽器打開就能用。

## 計算說明

- 八卦配五行依後天八卦。
- 四柱以台灣時間（UTC+8）計算，年柱以立春為界，月柱以節氣（太陽黃經）為界，23:00 之後算隔日子時。未校正真太陽時與日光節約時間。
- 五行強弱是簡化判斷：天干與地支本氣各計 1，月支計 2。
