# destiny

反思型的易經、五行工具原型。重點不是算命，而是給人一個換角度思考的方向。

## 檔案

- `index.html`：首頁「掌上命珠」，列出下面六個工具。
- `wuxing-wengua.html`：五行問卦。用生辰排出八字四柱，看日主和五行強弱；再擲硬幣起卦看這件事，最後合看陰陽和五行喜忌。
- `wuxing-hepan.html`：舊網址，會自動轉到五行問卦。
- `ziwei-mingpan.html`：紫微斗數命盤。用國曆生辰和性別排出十二宮方盤，含主星、輔星、雜曜、廟旺、生年四化、大限、長生與博士十二神；點宮位會標出三方四正並說明星曜。
- `xingzuo-mingpan.html`：西洋星座命盤。輸入出生日期、時間和地點，排出本命星盤，含三大星座、十大行星與北交點的星座和宮位、主要相位和十二宮。
- `renleitu.html`：人類圖。依出生時間與地點算出個性（出生時）與設計（太陽倒退 88 度時）各 13 個啟動，畫出簡化人體圖，列出類型、策略、內在權威、人生角色、定義、通道、九大中心與輪迴交叉的四個閘門。不知道出生時間時，會把當天 24 小時都算過，標出不確定的結果。
- `taluo.html`：塔羅。上段「生日牌」用出生日期算出人格牌與靈魂牌；下段「抽牌」從 78 張牌中抽一張或三張（過去・現在・未來，或現況・阻礙・建議），可選擇包含逆位。牌面與說明文字皆為本站自製。
- `shuangren-hepan.html`：雙人合盤。輸入兩個人的生辰和關係（伴侶、朋友、家人、工作夥伴），從五行（日主生剋、喜用、五行互補）、八字（日干五合、日支合沖刑）、生肖、八宅命卦遊年，以及星座（日月金火元素、交叉相位、宮位疊圖）整理出相似、互補和摩擦的地方。不知道出生時間也能用。

都是單一 HTML 檔，直接用瀏覽器打開就能用。紫微命盤、星座命盤、人類圖和雙人合盤需要連網，從 jsDelivr 載入計算用的函式庫。

## 計算說明

- 八卦配五行依後天八卦。
- 四柱以台灣時間（UTC+8）計算，年柱以立春為界，月柱以節氣（太陽黃經）為界，23:00 之後算隔日子時。未校正真太陽時與日光節約時間。
- 五行強弱是簡化判斷：天干與地支本氣各計 1，月支計 2。
- 紫微斗數排盤使用開源的 [iztro](https://github.com/SylarLong/iztro)（MIT 授權）。23:00 之後出生以隔日子時排盤。
- 星座命盤用 [astronomy-engine](https://github.com/cosinekitty/astronomy)（MIT 授權）算行星位置，回歸黃道、普拉西度分宮制、平均北交點。已和 Swiss Ephemeris 比對，行星、上升、天頂和宮首誤差在 0.02° 以內。
- 八宅命卦以出生年（立春為界）和性別計算，男命 (11 − 年 mod 9) mod 9、女命 (年 mod 9 + 4) mod 9，餘 0 作 9，5 則男坤女艮；兩人關係依兩卦相差的爻位對應八宅遊年（生氣、延年、天醫、伏位、禍害、六煞、五鬼、絕命）。
- 人類圖：閘門從 41 號（302°）起、每閘門 5.625°、每爻 0.9375°；交點用真交點；設計時間為出生前太陽倒退 88° 的時刻。已和開源的 natalengine 比對 500 組隨機出生時間，閘門、爻、類型、權威、人生角色、中心與通道全部一致；真交點與 Swiss Ephemeris 相差 40 角秒以內。
- 塔羅生日牌：出生年＋月＋日，各位數加總到 22 以內為人格牌（22 為愚者）；若為兩位數再加一次為靈魂牌（19 會得到 19、10、1 三張）。
